# Unemployment Analysis in India

## Project Overview
This project analyzes unemployment trends in India using Python and data visualization.

## Objectives
- Analyze unemployment rates across Indian states.
- Study monthly unemployment trends.
- Understand unemployment patterns during COVID-19.
- Compare rural and urban unemployment rates.
- Identify seasonal unemployment patterns.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Structure
- `main.py` – Main analysis program
- `Unemployment in India.csv` – Dataset
- `outputs/` – Generated graphs

## How to Run
1. Install dependencies using `pip install -r requirements.txt`.
2. Run `python main.py`.

## Output
The project generates multiple visualizations to understand unemployment trends in India.

## Conclusion
This analysis provides insights into regional, monthly, rural and urban unemployment patterns in India.
